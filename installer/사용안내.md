# 스킬에 포함된 설치 도우미

스킬이 이미 설치돼 있고 채팅 도구가 내 컴퓨터의 명령을 실행할 수 있다면, “HWPX 작업에 필요한 설치 상태를 확인하고 준비해 줘”라고 요청하세요. 스킬 안의 도우미로 필요한 파일을 설치하고 원래 작업을 이어갑니다. ZIP을 다시 받을 필요가 없습니다.
직접 실행하려면 스킬 폴더의 `설치하기.cmd`(Windows) 또는 `설치하기.command`(Mac)를 엽니다.

## 로컬 실행이 불가능한 채팅에서 다운로드하기

1. 채팅에서 제공한 `hwpx-setup.zip` 링크를 눌러 내려받습니다.
2. ZIP을 **모두 압축 해제**하고, 나온 `hwpx` 폴더를 계속 보관할 위치에 둡니다.
3. Windows는 `설치하기.cmd`, Mac은 `설치하기.command`를 엽니다.
4. Python 또는 Node.js가 없다고 나오면 안내된 공식 페이지에서 설치한 뒤 설치하기를 다시 엽니다. Python은 3.10 이상, Node.js는 22 이상이 필요합니다.
5. 완료되면 같은 폴더의 `시작하기.cmd` 또는 `시작하기.command`를 열어 에디터를 시작합니다.

설치에는 인터넷 연결이 필요합니다. Git이나 한컴오피스는 필요하지 않습니다.
패키지는 이 폴더의 `.venv`에 설치됩니다. 설치 후 폴더를 이동하면 `.venv`를 삭제하고 다시 설치하세요.
기본 에디터는 브라우저에서 열리며 pywebview는 필수가 아닙니다.
변환 엔진은 해당 변환 기능을 처음 사용할 때 추가로 내려받습니다.

## 설치가 멈췄을 때

- Python: https://www.python.org/downloads/
- Node.js: https://nodejs.org/en/download/ 에서 LTS 설치 파일을 받습니다.
- 설치 직후에도 찾지 못하면 설치 창을 닫고 다시 엽니다.
- Mac에서 실행을 차단하면 시스템 설정의 개인정보 보호 및 보안에서 해당 파일의 출처를 확인합니다. 관리 기기에서 차단된 경우 관리자에게 문의합니다. 보안 기능 전체를 끄지 마세요.
- 에디터 다운로드 실패는 인터넷 연결을 확인한 뒤 재실행합니다.
- 오류가 계속되면 폴더의 `install.log`와 화면의 오류를 채팅에 전달합니다.

## 채팅 도구에 연결하기

이 도우미는 컴퓨터에 필요한 파일을 준비합니다. ChatGPT나 Claude 계정에 스킬을 자동 등록하거나 일반 채팅 앱에 로컬 명령 실행 권한을 부여하지 않습니다.
로컬 파일과 명령을 사용할 수 있는 도구에서는 이 폴더의 `SKILL.md`를 읽도록 하고, 점검 결과의 `python` 경로로 Python 스크립트를 실행하게 합니다.
Claude Code에 등록하려면 설치 전에 이 폴더를 사용자 홈의 `.claude/skills/hwpx`에 둡니다. 다른 도구의 등록 방법은 해당 도구에서 지원하는 방법을 따릅니다.
웹/클라우드 채팅의 실행 환경과 사용자 PC는 별개입니다. 클라우드에서 점검한 결과가 사용자 PC의 설치 완료를 뜻하지 않습니다.
