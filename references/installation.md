# 내장 설치 도우미 실행과 다운로드 안내

## 점검

이 대화가 사용자 PC에서 로컬 명령을 실행하는 환경인지 먼저 구분한다. 클라우드 컨테이너의 OS나 파일로 사용자 PC의 상태를 추정하지 않는다.
로컬 실행이 가능하면 스킬 폴더에서 `python3 scripts/install_helper.py --check`를 실행한다. Windows는 `py -3` 또는 `python`을 사용한다. Python 자체가 없으면 설치 안내로 이동한다.
점검은 네트워크나 파일 변경 없이 JSON을 반환한다. `documents_ready`는 문서 패키지와 Node, `editor_ready`는 에디터 파일까지 준비됐다는 뜻이다. 변환 엔진 다운로드와 실제 화면 실행을 보증하지 않는다.
반환된 `python` 경로(설치 도우미의 `.venv` 우선)를 이후 Python 작업에 사용한다. 시스템 Python에 패키지를 재설치하지 않는다.
문서 작업이면 `documents_ready`, 에디터 작업이면 `editor_ready`가 참일 때 본 작업으로 진행한다. 에디터가 없다고 단순 문서 읽기를 막지 않는다.

## 내장 도우미 우선 실행

사용자 PC에서 명령을 실행할 수 있고 필요한 항목이 빠졌으면, 별도의 ZIP을 다시 받게 하지 않고 스킬 폴더의 도우미를 실행한다. 설치 작업이 사용자 요청과 실행 권한 범위에 포함되면 진행하며, 실행 환경이 요구하는 승인은 따른다.

1. 사용자에게 필요한 패키지와 에디터를 준비한다고 짧게 알린다.
2. 스킬 폴더에서 `python3 scripts/install_helper.py --install`을 실행한다. Windows는 사용 가능한 `py -3` 또는 `python`을 사용한다. 스킬 경로에 공백이 있으면 경로를 인용한다.
3. 종료 코드가 0일 때 `--check`를 다시 실행한다. 필요한 기능이 준비되었는지 확인하고, 반환된 `python` 경로로 원래 문서 작업을 이어간다.
4. 실패하면 오류와 `install.log`를 확인한다. 같은 오류로 설치를 반복하지 말고 필요한 조치를 안내한다. Python·Node.js가 없거나 버전이 낮으면 공식 설치 페이지 또는 스킬 폴더에 이미 있는 `설치하기.cmd`/`설치하기.command`를 안내한다. 같은 파일을 다시 다운로드하게 하지 않는다.

명령으로 실행할 때는 입력을 기다리는 더블클릭용 파일 대신 Python 도우미를 직접 호출한다. 패키지는 스킬 폴더의 `.venv`에 설치한다. 스킬 폴더에 쓰기 권한이 없으면 쓰기 가능한 위치로 옮기도록 안내하며 시스템 전역 설치로 우회하지 않는다.
클라우드에서 도우미를 실행해도 사용자 PC에 설치되는 것은 아니다. 클라우드 작업용 설치와 사용자 PC 설치를 구분하고, 사용자 PC에 설치하려는 요청에서는 아래 다운로드 경로로 안내한다.

## 로컬 실행이 불가능할 때만 다운로드 제공

배포 주소: https://github.com/HooniKims/hwpx/releases/download/installer-v1/hwpx-setup.zip

파일 첨부를 지원하면 스킬에 포함된 도우미와 의존 파일을 묶은 ZIP 첨부를 우선한다. 실행 파일 하나만 보내면 상대 경로의 스크립트가 없어 실행되지 않으므로 전체 패키지를 제공한다. 첨부를 지원하지 않으면 공개 다운로드 링크를 사용한다.

링크를 제공하기 전에 HTTP 응답 또는 GitHub 릴리스 정보로 파일 존재를 확인한다. 게시 전이거나 확인 불가능하면 다운로드 가능하다고 단정하지 않는다. 로컬 첨부를 지원하는 환경에서는 `python3 scripts/package_installer.py`로 만든 `dist/hwpx-setup.zip`을 첨부할 수 있다. 소스 폴더 경로 자체를 다운로드 링크로 제시하지 않는다.

사용자 OS가 확인되면 해당 실행 파일만 안내한다. 로컬 상태를 확인할 수 없고 사용자 OS도 모르면 Windows/Mac 중 무엇인지 묻는다. 이미 설치됐다는 사용자 응답이 있으면 불필요하게 다시 설치시키지 않는다.

예시(파일 게시 확인 후):

> 처음 사용하려면 설치 파일을 준비해 주세요.
> [설치 도우미 다운로드](https://github.com/HooniKims/hwpx/releases/download/installer-v1/hwpx-setup.zip)
> ZIP을 모두 압축 해제하고 **설치하기.cmd**를 열어 주세요. 완료 후 **시작하기.cmd**를 열면 됩니다.

Mac에서는 `.command`로 안내한다. 링크 클릭은 다운로드이며 실행은 사용자가 직접 한다. 추가 프로그램이 필요하면 공식 설치 페이지 안내가 나올 수 있다고 설명한다.
자세한 문제 해결과 앱 연결 범위는 `installer/사용안내.md`를 참고한다.

## 관리자 배포

`python3 scripts/package_installer.py`로 ZIP을 만든다. `.venv`, 로그, 빌드 캐시는 포함되지 않는다.
GitHub Actions의 **Package installer**를 수동 실행하면 검증 후 ZIP을 Actions artifact로 올린다. `publish`를 선택하면 `installer-v1` 릴리스에 ZIP과 SHA-256을 게시/교체한다. 반드시 배포하려는 커밋에서 실행한다.
새 배포 전 Windows와 macOS에서 압축 해제 → 설치 → 시작 흐름을 확인한다. 서명된 네이티브 설치 프로그램은 아니므로 OS 보안 확인이 나타날 수 있다.
